
### Categories of Unsupervised Learning

- **Clustering**: involves grouping a set of objects in such a way that objects in the same group are more similar (in some sense) to each other than to those in other groups.
- **Dimensionality Reduction**: The process of reducing the number of random variables under consideration by obtaining a set of principal variables. The goal is to map data from a high-dimensional space $x \in \mathbb{R}^d$ to a lower-dimensional space $\mathbf{z} \in \mathbb{R}^p$ where $p \ll d$, while preserving as much "meaningful" information as possible.
- **Anomaly detection**: Involves identifying outliers, which raise suspicions by differing significantly from the majority of the data.
