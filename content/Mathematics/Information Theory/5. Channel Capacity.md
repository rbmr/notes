### Preliminary Knowledge

This note assumes familiarity with entropy and mutual information ([[1. Entropy and Information Measures]]), and the definition of a concave function together with rules for recognizing concavity ([[Non-Linear Optimization#Convexity]]).

### Channel Model

- A **discrete memoryless channel (DMC)** is described by an input alphabet $\mathcal X$, an output alphabet $\mathcal Y$, and a fixed conditional distribution $p(y\mid x)$ (the "channel"), such that each symbol sent through the channel is corrupted independently of every other symbol (memoryless), according only to the current input (no feedback from past outputs back into the channel's behavior).
- Given a choice of input distribution $p(x)$, the channel induces a joint distribution $p(x,y)=p(x)p(y\mid x)$, hence an output distribution $p(y) = \sum_x p(x)p(y\mid x)$ and a mutual information $I(X;Y)$ — how much, on average, observing the output reveals about the input.

### Channel Capacity

- The **channel capacity** is the largest achievable mutual information, optimized over input distributions, for a fixed channel $p(y\mid x)$:
	$$
	C = \max_{p(x)} I(X;Y)
	$$
	Intuition: the best possible rate (in bits per channel use) at which information can be pushed through the channel, if the sender is free to choose how to distribute their input symbols.
- **This maximization is a genuine (concave) optimization problem**, so a global maximum is guaranteed to exist and be found by standard tools such as the Lagrangian:
	1. $I(X;Y) = H(Y) - H(Y\mid X)$. The second term, $H(Y\mid X) = \sum_x p(x)H(Y\mid X=x)$, is a *linear* function of $p(x)$, since each $H(Y\mid X=x)$ is a fixed number (determined by the channel alone) being weighted by $p(x)$.
	2. The first term, $H(Y) = -\sum_y p(y)\log p(y)$, is a concave function of the vector $p(y)$: each summand $-p(y)\log p(y)$ is concave in $p(y)$ (second derivative $-1/p(y) < 0$), and a sum of concave functions is concave.
	3. $p(y)$ is itself a *linear* (affine) function of $p(x)$: $p(y) = \sum_x p(x)p(y\mid x)$. Composing a concave function with an affine map preserves concavity, so $H(Y)$ is concave as a function of $p(x)$ too.
	4. $I(X;Y) = H(Y)-H(Y\mid X) = (\text{concave}) - (\text{linear})$ is concave in $p(x)$.
	5. The set of valid input distributions (the probability simplex over $\mathcal X$) is convex, so maximizing a concave function over it is a convex optimization problem: every local maximum is global.
	- (Solving this maximization explicitly, e.g. via the Blahut-Arimoto algorithm, is an iterative application of the Lagrangian/KKT machinery to this concave problem — a computational detail beyond the scope of this note.)

### Examples

- **Noiseless binary channel** ($Y=X$, no corruption): $H(Y\mid X)=0$ regardless of $p(x)$, so $I(X;Y)=H(Y)\le 1$, maximized (at $1$ bit) by a uniform input. So $C=1$: every input bit is recovered perfectly.
- **Binary symmetric channel (BSC)** with crossover probability $q$ (each bit is flipped independently with probability $q$): $H(Y\mid X=x)$ equals the binary entropy $H_b(q) = -q\log q-(1-q)\log(1-q)$ regardless of which bit $x$ was sent (a $0$ or a $1$ is each garbled with the same probability $q$), so $H(Y\mid X) = H_b(q)$ for *every* input distribution. Then $I(X;Y) = H(Y)-H_b(q) \le 1-H_b(q)$, with equality when $Y$ is uniform, which (by symmetry of the channel) happens exactly when $X$ is uniform. So $C = 1-H_b(q)$.
	- Sanity checks: $q=0$ (no noise) gives $C=1$; $q=\frac12$ (output independent of input) gives $H_b(\frac12)=1$, so $C=0$ — no information gets through, matching the intuition that a coin-flip channel destroys the input entirely.
- **Binary erasure channel (BEC)** with erasure probability $\alpha$ (each bit is either transmitted correctly, or replaced with a distinguishable "erasure" symbol $e$, with probability $\alpha$): $C=1-\alpha$. Roughly: a fraction $\alpha$ of the bits are unusable (but the receiver at least knows *which* ones), so the surviving fraction $1-\alpha$ carries information at rate $1$.

### The Noisy-Channel Coding Theorem

- **Shannon's noisy-channel coding theorem**: for any rate $R<C$, there exist codes (mapping length-$n$ blocks of message bits into channel inputs, for $n$ large enough) that permit the message to be recovered with error probability arbitrarily close to $0$. For $R>C$, no such code exists — the error probability is bounded away from $0$ regardless of how the code is designed.
- Intuition sketch (not a full proof — the real proof uses a random-coding argument together with the joint version of the AEP, see [[2. Asymptotic Equipartition Property]]): fix a typical output sequence $y^n$. By the AEP, there are roughly $2^{nH(X\mid Y)}$ input sequences $x^n$ that are "jointly typical" with (i.e., plausibly could have produced) that particular $y^n$, out of roughly $2^{nH(X)}$ typical input sequences overall. If the sender picks $2^{nR}$ codewords at random from the $2^{nH(X)}$ typical inputs, the chance that some *other* codeword also lands in $y^n$'s pool of $2^{nH(X\mid Y)}$ plausible causes is small whenever $2^{nR}\cdot 2^{nH(X\mid Y)} \ll 2^{nH(X)}$, i.e. whenever $R < H(X)-H(X\mid Y) = I(X;Y)$. Optimizing the input distribution to make $I(X;Y)$ as large as possible gives exactly the threshold $R<C$.
