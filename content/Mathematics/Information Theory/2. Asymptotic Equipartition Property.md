### Preliminary Knowledge

This note assumes familiarity with entropy ([[1. Entropy and Information Measures]]), the weak law of large numbers ([[6. Limit Theorems]]), and the binomial coefficient ([[Combinatorics]]).

### Setup

Let $X_1, X_2,\ldots$ be i.i.d. draws from a discrete distribution $p(x)$, and write $X^n = (X_1,\ldots,X_n)$ for a length-$n$ sequence. Since the $X_i$ are independent, the probability of a specific sequence factors:
$$
p(x^n) = \prod_{i=1}^n p(x_i)
$$

### The Asymptotic Equipartition Property

- Consider the (random) quantity $-\frac1n\log p(X^n) = -\frac1n\sum_{i=1}^n \log p(X_i)$: the average self-information per symbol. It is a sample mean of the i.i.d. terms $-\log p(X_i)$, each with expected value $E[-\log p(X_i)] = H(X)$.
- **The Asymptotic Equipartition Property (AEP)**: by the weak law of large numbers applied to these i.i.d. terms,
	$$
	-\frac1n\log p(X^n) \xrightarrow{\ P\ } H(X) \quad\text{as } n\to\infty
	$$
	That is, for every $\epsilon>0$, $P\left(\left|-\frac1n\log p(X^n) - H(X)\right| < \epsilon\right) \to 1$.
- Interpretation: for large $n$, almost all of the probability mass concentrates on sequences whose probability is close to $2^{-nH(X)}$ — even though individual sequences can still have wildly different probabilities in principle, "almost all" outcomes behave as if they were (nearly) equiprobable, hence the name.

### Typical Sets

- The **$\epsilon$-typical set** $A_\epsilon^{(n)}$ is the set of length-$n$ sequences whose average self-information is within $\epsilon$ of the entropy:
	$$
	A_\epsilon^{(n)} = \left\{x^n : \left|-\frac1n\log p(x^n) - H(X)\right| < \epsilon\right\}
	$$
	Equivalently, every $x^n \in A_\epsilon^{(n)}$ satisfies $2^{-n(H(X)+\epsilon)} < p(x^n) < 2^{-n(H(X)-\epsilon)}$.
- **Property 1 — the typical set carries almost all the probability.** For any $\epsilon>0$ and $\delta>0$, there is an $n_0$ such that for $n\ge n_0$, $P(A_\epsilon^{(n)}) > 1-\delta$. This is immediate from the AEP (convergence in probability is exactly the statement that this event's probability tends to $1$).
- **Property 2 — the typical set is small relative to all sequences.** For all $n$: $|A_\epsilon^{(n)}| \le 2^{n(H(X)+\epsilon)}$.
	1. Every element of $A_\epsilon^{(n)}$ has probability at least $2^{-n(H(X)+\epsilon)}$.
	2. Summing this lower bound over all elements of $A_\epsilon^{(n)}$ cannot exceed the total probability $1$: $1 \ge \sum_{x^n\in A_\epsilon^{(n)}} p(x^n) \ge |A_\epsilon^{(n)}|\cdot 2^{-n(H(X)+\epsilon)}$.
	3. Rearranging gives $|A_\epsilon^{(n)}| \le 2^{n(H(X)+\epsilon)}$.
- **Property 3 — the typical set is large enough to matter.** For $n$ large enough, $|A_\epsilon^{(n)}| \ge (1-\delta)2^{n(H(X)-\epsilon)}$.
	1. By Property 1, for $n$ large enough, $\sum_{x^n\in A_\epsilon^{(n)}} p(x^n) = P(A_\epsilon^{(n)}) > 1-\delta$.
	2. Every element of $A_\epsilon^{(n)}$ has probability at most $2^{-n(H(X)-\epsilon)}$, so $\sum_{x^n\in A_\epsilon^{(n)}} p(x^n) \le |A_\epsilon^{(n)}|\cdot 2^{-n(H(X)-\epsilon)}$.
	3. Combining: $1-\delta < |A_\epsilon^{(n)}|\cdot 2^{-n(H(X)-\epsilon)}$, i.e. $|A_\epsilon^{(n)}| > (1-\delta)2^{n(H(X)-\epsilon)}$.
- Combining Properties 2 and 3: $|A_\epsilon^{(n)}| \approx 2^{nH(X)}$, while the full sample space has up to $|\mathcal X|^n$ sequences. When $H(X) < \log|\mathcal X|$ (i.e. $X$ is not uniform), the typical set is an exponentially vanishing fraction of all sequences that nonetheless captures almost all the probability — this is the combinatorial heart of data compression (see [[4. Source Coding]]).

### Concrete Illustration: Bernoulli Sequences

To make the abstract bound $|A_\epsilon^{(n)}| \approx 2^{nH(X)}$ tangible, consider $X\sim\text{BERNOULLI}(p)$, so a length-$n$ sequence is a binary string. A sequence with exactly $k$ ones has probability $p^k(1-p)^{n-k}$, and there are $\binom nk$ such sequences.

- Fix a proportion $k=np$ (assume this is an integer for simplicity) — the "typical" number of ones, by the law of large numbers. Using Stirling's approximation ($n! \sim \sqrt{2\pi n}(n/e)^n$, a standard asymptotic fact) on the binomial coefficient:
	$$
	\binom{n}{np} = \frac{n!}{(np)!(n(1-p))!} \approx 2^{nH_b(p)}
	$$
	where $H_b(p) = -p\log p-(1-p)\log(1-p)$ is the binary entropy function (the entropy of a single BERNOULLI$(p)$ trial). This is the same $2^{nH}$ count predicted by Properties 2/3 above, now derived by direct combinatorial counting rather than the probabilistic AEP argument — two routes to the same number.
- This also shows why the typical set is such a small fraction of all $2^n$ binary strings whenever $p\ne\frac12$: $H_b(p) < H_b(\frac12)=1$ for any $p\ne\frac12$, so $2^{nH_b(p)} \ll 2^n$.
