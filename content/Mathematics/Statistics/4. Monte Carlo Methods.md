### Monte Carlo Simulation

The core idea: *"I don't know how to calculate it directly, so I'll estimate it."* 

Named after the Monte-Carlo casino, the method was invented by Stanisław Ulam (1946, Los Alamos), who estimated a solitaire win probability by playing many random games rather than by combinatorics.

To estimate an unknown but fixed quantity $\mu$:
1. Find a random variable $X$ that we can sample from with expected value $E[X] = \mu$ and finite variance $\text{Var}(X) = \sigma^2 < \infty$.
2. Draw $n$ i.i.d. copies $X_1, \dots, X_n$.
3. Estimate $\mu$ by the sample mean $\bar X_n = \frac{1}{n}\sum_{i=1}^n X_i$.

Properties:
- By Strong Law of Large Numbers the estimate is a consistent estimator.
-  $\text{Var}(\bar X_n) = \sigma^2/n$, so halving the standard error costs $4\times$ the samples.
- By the Central Limit Theorem, the estimate follows an approximately normal distribution, which can be used to estimate the confidence interval.

A Monte Carlo estimator should be cheap to sample from, and have low variance. Sampling efficiency is a matter of the [[3. Random Variate Generation|Random Variate Generation]], the variance we can tackle directly via [[4. Monte Carlo Methods#Variance Reduction|Variance Reduction]].

### Monte Carlo Integration

The most common use is estimating an integral that has no closed form, by rewriting it as the expectation of a (function of a) random variable we can sample from.

1. Start from $\theta$ defined as an integral.
2. Rewrite it as $\theta = E[g(X)]$ for a random variable $X$ you can sample from.
3. Apply Monte Carlo: draw independent $X_1,\dots,X_n$, compute $g(X_i)$, and take the average. 
	$$
	\hat\theta_n = \frac{1}{n}\sum_{i=1}^n g(X_i)
	$$
4. Since $X_{i}$ are independent, so are $g(X_{i})$. Then our estimator $\hat{\theta}_{n}$ is unbiased $E[\hat\theta_n]=\theta$ and consistent $\hat\theta_n \xrightarrow{a.s.} \theta$ by the SLLN.

Example 1: arbitrary function $h$ over a finite interval $[a,b]$:
$$
\theta = \int_a^b h(x)\,dx = (b-a)\int_a^b h(x)\, \tfrac{1}{b-a}dx = (b-a)\,E[h(X)]
$$
where $X \sim U(a,b)$.

### Hypothesis Testing via Simulation

A hypothesis test needs the distribution of the test statistic $T$ under $H_0$. When that distribution is unknown or intractable, we can also estimate it. For example, take a test that rejects $H_0$ when $T$ is large.

**Estimating the critical region** (via order statistics):
1. Draw i.i.d. datasets $X^1, X^2, \dots, X^n$ from $H_0$.
2. Compute the test statistic on each, $t_i := T(X^i)$.
3. Sort them, let $t_{(i)}$ be the $i$-th order statistic. The estimated critical region is the empirical $(1-\alpha)$ quantile and above:
	$$
	\hat{\mathcal C}_\alpha := \big[\,t_{(\lceil (1-\alpha)n\rceil)},\ \infty\,\big).
	$$
4. Reject $H_0$ if the observed $t_{\text{obs}} \in \hat{\mathcal C}_\alpha$.

**Estimating the $p$-value** (via a sample mean). Since a $p$-value is a probability, it is the expectation of an indicator:
$$
p = P_{H_0}(T > t_{\text{obs}}) = E_{H_0}\big[\mathbb 1(T > t_{\text{obs}})\big].
$$
1. Draw datasets $X^1,\dots,X^n$ i.i.d. from $H_0$.
2. For each, compute $\mathbb 1(T(X^i) > t_{\text{obs}})$.
3. Estimate $\hat p_n = \frac{1}{n}\sum_{i=1}^n \mathbb 1(T(X^i) > t_{\text{obs}})$, and reject if $\hat p_n \le \alpha$.

Note on reliability: The $p$-value estimate $\hat p_n$ is a *sample mean*, so the Law of Large Numbers gives it an asymptotic performance guarantee. The critical-region estimate is a *sample quantile*, which lacks the same guarantee, therefore the $p$-value approach is generally preferred. 

### Variance Reduction

As discussed, the variance Monte Carlo estimate can be made to have lower variance by increasing the sample size $n$, or reducing the variance of each estimate directly. In this section we focus on the latter. 

Main idea: reduce variance of an estimator by exploiting the covariances between different random variables:
$$
\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)+2\text{Cov}(X,Y)
$$

**Antithetic Variables**: suppose we want to estimate $\theta=\mathbb{E}[g(Z)]$ for some function $g$ where $Z$ follows a symmetrical distribution with mean $\mu_{Z}$. Consider the antithetic random variable $2\mu_{Z}-Z$. Both $Z$ and $2\mu_{Z}-Z$ follow the same distribution. Therefore we can combine both while remaining unbiased:
$$
\hat\theta_n^{a} = \frac{1}{n}\sum_{i=1}^n \frac{g(Z_i) + g(2\mu_Z - Z_i)}{2}, \quad \mathbb{E}[\hat{\theta}_{n}^a]=\theta
$$
The variance reduces to: $\text{Var}(\hat{\theta}_{n}^a)=\frac{1}{2n}[\text{Var}(g(Z))+\text{Cov}(g(Z),g(2\mu_{Z}-Z))]$.

Comparing against the standard Monte Carlo estimator $\hat{\theta}_{n}=\frac{1}{n}\sum_{i=1}^n g(Z_{i})$, with variance $\text{Var}(\hat{\theta}_{n})=\frac{Var(g(Z))}{n}$, we get:
- $\text{Var}(\hat{\theta}_{n}^a) \leq \text{Var}(\hat{\theta}_{n})$ in all cases.
- $\text{Var}(\hat{\theta}_{n}^a)<\text{Var}(\hat{\theta}_{n})$ if and only if $\text{Cov}(g(Z),g(2\mu_{Z}-Z)) < \text{Var(g(Z))}$.

However, this arguably not a fair comparison, since we use twice as many evaluations of $g$, correcting for this we get:
- $\text{Var}(\hat{\theta}^a_{n})\leq \text{Var}(\hat{\theta}_{2n})$ if and only if $\text{Cov}(g(Z), g(2\mu_{Z}-Z)) \le 0$
- $\text{Var}(\hat{\theta}^a_{n})\lt \text{Var}(\hat{\theta}_{2n})$ if and only if $\text{Cov}(g(Z), g(2\mu_{Z}-Z)) < 0$
- This is the case when $g$ is a monotonic function, and not the case when $g$ is highly symmetric around $\mu_{Z}$.

**Control Variates**: suppose want to estimate unknown mean of a random variable $Y$, but $\text{Var}(Y)$ is large. We relate $Y$ to another random variable $X$ with known mean. Define the control variate correction: $Y_{c}=Y+c(X-\mu_{X})$ for some $c \in \mathbb{R}$, then:
$$
\mathbb{E}[Y_{c}]=\mathbb{E}[Y+c(X-\mu_{X})]=\mathbb{E}[Y] +c(\mathbb{E}[X]-\mu_{X})=\mu_{Y}
$$
So $Y_{c}$ remains unbiased. We then pick $c$ based on the covariance between $X$ and $Y$, such that $\text{Var}(Y_{c})$ is as small as possible. In the worst case the covariance is zero and no variance reduction is possible.
