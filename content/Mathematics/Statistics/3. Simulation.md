### Simulation

What is simulation? Basically: "I dont know how to calculate it directly, so Ill just estimate it". 

The key idea lies in Monte Carlo Simulation:
1. Given some quantity to estimate $\mu$.
2. Determine an estimator $X_{i}$ with mean $E[X_{i}]=\mu$ and finite variance $Var(X_{i})=\sigma^2$ that we can sample from. 
3. We estimate $\mu$ by taking $n$ samples from $X_{i}$, and computing the average $\bar{X}_{n}=\frac{1}{n} \sum_{i=1}^{n}X_{i}$. 
4. We know, by the strong law of large numbers that $\lim_{ n \to \infty }\bar{X}_{n}=\mu$, therefore $\bar{X}_{n}$ becomes an increasingly good estimator of $\mu$ as $n$ increases.

Essentially: we do statistics on data we generate ourselves. Notably, computational efficiency is relevant aswell. A better estimator is one you can sample from efficiently, and that has a lower variance.  

### Monte Carlo Integration

1. Given some quantity to estimate $\theta$ defined as an integral.
2. Rewrite the integral such that $\theta$ becomes the expected value of some random variable $g(X)$, where you are capable of sampling from $X$. Specifically, rewrite such that $\theta=E[g(X)]$.
3. Monte Carlo simulation is then simply:
	1. Draw $n$ independent realizations of the random variable $X_{1},X_{2},\dots,X_{n}$.
	2. Compute $g(X_{1}), g(X_{2}), \dots, g(X_{n})$. Since $X_{i}$ are independent, $g(X_{i})$ are also independent across all $i$.
	3. Estimate $\theta$ by sample average: $\hat{\theta}_{n}:= \frac{g(X_{1})+\dots+g(X_{n})}{n}$

### Estimating Critical Region

We have a test that rejects $H_{0}$ if the test statistic $T$ is large.

Suppose then, we want to compute the critical region, but we dont know the distribution of the test statistic under $H_{0}$. Instead, we can estimate the critical region as follows:
1. Draw i.i.d. data sets $X^{1}, X^2, \dots, X^n$, i.i.d. from $H_{0}$.
2. For each dataset compute the test statistics $t_{i}:=T(X^i)$.
3. Sort them and let $t_{(i)}$ be the $i$-th order statistic.
4. The estimated critical region is then $\hat{\mathcal{C}}_{\alpha}:= [t_{(\lceil (1-\alpha)n \rceil)},\infty)$
5. We reject if $t_{obs}\in \hat{\mathcal{C}}_{\alpha}$.

Similarly, to estimate the p-value observe that:
$$
p:=\mathbb{P}_{H_{0}}(T>t_{obs})=\mathbb{E}_{H_{0}}[\mathbb{1}_{(T >t_{obs})}]
$$
So we can estimate the $p$ value as follows:
1. Draw data sets $X^1, X^2, \dots, X^n$ i.i.d. from $H_{0}$.
2. For each observation $i$, compute $T(X^i)$ and $\mathbb{1}_{(T(X^i)>t_{obs})}$
3. Estimated p-value: $\hat{p}_{n}:=\frac{1}{n}\sum^n_{i=1} \mathbb{1}_{(T(X^i)>t_{obs})}$
4. Reject if $\hat{p}_{n}\leq \alpha$

Via the LLN we have an asymptotic performance guarantee for $\hat{p}_{n}$, but not $\hat{\mathcal{C}}_{\alpha}$, therefore the latter is generally preferred.

### Random Variate Generation

**Random variate generation**: we sample from a probability distribution by first using a RNG to sample from $U(0, 1)$, and transforming these numbers into draws from an arbitrary distribution $F$. (TODO: generalize this as "how to sample from distributions")

**Inverse Transform Method** we generate $U \sim U(0,1)$, and return $F^{-1}(U)$. This is the simplest method there is. Applicability depends on availability of accurate formula for the (generalized) inverse CDF of $F^{-1}$.
- Relevant Theorem: Let $U \sim U(0,1)$ and let $F$ be a continuous CDF that is strictly monotonically increasing. Then, the random variable $X=F^{-1}(U)$ has CDF $F$.

**Methods using special properties** suppose we want to simulate the value of a random variable $X$, and we know that $X \sim g(Y_{1}, \dots, Y_{n})$ for some r.v. $Y_{i}$ and some function $g(y)$. If we know how to generate each of the $Y_{i}$'s then we can generate $X$ as follows: (1) generate $Y_{1}, \dots, Y_{n}$. (2) Return $X = g(Y_{1}, \dots, Y_{n})$. 
- The case where $g(Y_{1}, \dots, Y_{n})=Y_{1}+\dots+Y_{n}$ is called the **convolution method**.
- **Example 1**: To generate $X \sim \text{Gamma}(n,\lambda)$ (where $n \in \mathbb{N}$), generate $Y_1, \dots, Y_n \sim \text{Exp}(\lambda)$, return $X = \sum_{i=1}^n Y_i$.
- **Example 2**: To generate $X \sim \text{Beta}(\alpha,\beta)$, generate $Y_1 \sim \text{Gamma}(\alpha,1)$ and $Y_2 \sim \text{Gamma}(\beta,1)$, return $X = \frac{Y_1}{Y_1+Y_2}$.
- **Example 3**: To generate $X \sim \chi^2_{n}$, generate $Y_1, \dots, Y_n \sim N(0,1)$, return $X = \sum_{i=1}^n Y_i^2$.
- **Example 4**: To generate $Z \sim t_n$, generate $X \sim N(0,1)$ and $Y \sim \chi_{n}^2$, return $Z = \frac{X}{\sqrt{Y/n}}$.

**Acceptance Rejection Method**: generate a random variable using an easy distribution, and use a rule to decide whether to accept it as a sample of $X$ or not. 
- To ensure generated values accurately represent the target distribution $f(x)$ we must compare $f(x)$ to our easy distribution $g(x)$. That is, we must find a constant $c$ such that $f(x) \leq cg(x)$ for all $x$. The function $t(x)=cg(x)$ is referred to as the **majorizing function**. To find the smallest $c$ for which this holds (which minimizes number of rejects), you calculate $c^*=\sup_{x}\frac{f(x)}{g(x)}$. 
- The algorithm becomes:
	1. Generate $Y$ with density $g(y)$.
	2. Generate a standard uniform variable $U \sim U(0,1)$, independent of $Y$.
	3. If $U \leq \frac{g(Y)}{cg(Y)}$, accept the value by setting $X = Y$ and stop.
	4. Otherwise reject $Y$ and return to Step 1.
- The efficiency of this method is heavily dependent on the constant $c$. The overall area under $f(x)$ is $1$, whereas the area under $t(x)$ is $c$. Therefore the probability of accepting on an arbitrary $Y$ is $1/c$. 
- A consequent tradeoff becomes keeping $c$ small, while keeping $g(x)$ simple enough to draw samples from.
- **Thinning method**: To sample from a non-homogeneous Poisson distribution with rate $\lambda(t)$, we generate arrivals with some "peak" arrival rate $\lambda^*=\max_{t}\lambda(t)$.  Next, you generate "trial" arrivals using a standard, homogeneous Poisson process at the peak rate, and then accept an arrival at $t$ with probability $\lambda(t)/\lambda^*$.
