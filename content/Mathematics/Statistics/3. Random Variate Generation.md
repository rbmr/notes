### Core Definitions

- A **random number generator** (**RNG**) is a system capable of generating a sequence of numbers that cannot (reasonably) be predicted better than by random chance.
- A **pseudorandom number generator** (**PRNG**) is an algorithm that produces a sequence of numbers deterministically, but in a way that they appear random.   
    - The fundamental goal of PRNGs is to produce **independent** and identically distributed draws from a **uniform** $U(0,1)$ distribution.  
- Because a PRNG operates deterministically, and has finite memory, the sequence must eventually become periodic.   
- Let $U_{1}, U_{2}, U_{3}, \dots$ be a sequence of numbers generated by a PRNG, then there exists some positive integers $P$, and $i_{0}$ such that $U_{i+P}=U_{i}$ for all $i \geq i_{0}$. The **period length** is defined as the smallest positive integer $P$ that satisfies this equation.   
- **Random Variate Generation** is the process of generating values that follow a specific probability distribution. This is most often done this by first generating samples from a $U(0,1)$ distribution and then using these samples to sample from more complex distributions.

### Linear Congruential Generator

- A **Linear Congruential Generator** (**LCG**) is a specific type of PRNG first proposed by Lehmer in 1949 that creates pseudorandom numbers using a recursive formula:  
    - $Z_{i+1}=(\alpha Z_{i}+c) \ \text{mod}\ m$.  
    - $U_{i+1}=Z_{i+1}/m$  
    - where all parameters are integers, and $Z_{0}$ is the seed, $m$ is the modulus, $\alpha$ is the multiplier, and $c$ is the shift.   
    - The possible values of $U$ are the fractions $\frac{0}{m}, \frac{1}{m}, \dots, \frac{m-1}{m}$, so the period length $P$ can never exceed $m$. When $P=m$, the generator is said to have a **full period**.  
- **Full Period Theorem**: The LCG $Z_{i}=(\alpha Z_{i-1}+c)(\text{mod} \ m)$ has a full period if and only if all of the following conditions hold:  
    - $c$ and $m$ are relatively prime (their only common divisor is $1$)  
    - $\alpha-1$ is divisible by all prime factors of $m$  
    - $\alpha -1$ is divisible by $4$ if $m$ is divisible by $4$.  
- Some classic LCGs include:  
    - MINSTD (Lewis, Goodman & Miller 1969): $m=2^{31}-1$, $\alpha=7^5$, $c=0$.
    - SUPER-DUPER (G. Marsaglia 1972): $m=2^{32}$, $\alpha=69069$, $c=0$ or $c=1$.  
    - Modern PRNGs are based on the same recursive idea, but are often more sophisticated.

### Inverse Transform Method

- The **generalized inverse** (or **quantile function**) of a CDF $F$ is defined as $F^{-1}(u) = \inf _{x}\{x : F(x) \ge u\}$ for $u \in (0,1)$. 
	- The generalized inverse is defined for *any* CDF, and whenever the ordinary inverse of $F$ exists (i.e. $F$ is continuous and strictly increasing) the two coincide.
- If $U \sim U(0,1)$, then $X = F^{-1}(U)$ has CDF $F$. 
	- This does not require continuity or strict monotonicity of $F$
- If $X$ has CDF $F$, where $F$ is continuous, then $F(X) \sim U(0,1)$. 
	- Here, continuity of $F$ is required. Strict monotonicity is not required.
- The **Inverse Transform Method** samples from a distribution using the generalized inverse. Specifically, determine $U \sim U(0,1)$ and return $X = F^{-1}(U)$. 
	- This is the simplest method there is, but applicability relies on having an accurate formula for the (generalized) inverse CDF $F^{-1}$.

### Methods Using Special Properties

- Key idea: Suppose we want to sample from a random variable $X$, and we know that $X = g(Y_{1}, \dots, Y_{n})$ for some r.v. $Y_{i}$ and some function $g(y)$. If we know how to generate each of the $Y_{i}$'s we can generate $X$ by generating $Y_{1}, \dots, Y_{n}$, and returning $X = g(Y_{1}, \dots, Y_{n})$.
- See [[3. Common Distributions|common distributions]] for some of these relationships.
- The case where $g(Y_{1}, \dots, Y_{n})=Y_{1}+\dots+Y_{n}$ is called the **convolution method**.  
- Example 1: To generate $X \sim \text{Gamma}(n,\lambda)$ (where $n \in \mathbb{N}$), generate independent $Y_1, \dots, Y_n \sim \text{Exp}(\lambda)$, return $X = \sum_{i=1}^n Y_i$.  
- Example 2: To generate $X \sim \text{Beta}(\alpha,\beta)$, generate independent $Y_1 \sim \text{Gamma}(\alpha,1)$ and $Y_2 \sim \text{Gamma}(\beta,1)$, return $X = \frac{Y_1}{Y_1+Y_2}$.  
- Example 3: To generate $X \sim \chi^2_{n}$, generate independent $Y_1, \dots, Y_n \sim N(0,1)$, return $X = \sum_{i=1}^n Y_i^2$.  
- Example 4: To generate $Z \sim t_n$, generate independent $X \sim N(0,1)$ and $Y \sim \chi_{n}^2$, return $Z = \frac{X}{\sqrt{Y/n}}$.

### Acceptance–Rejection Method

- **Key idea**: draw from an easy distribution $g(x)$ and use a rule to decide whether to keep the draw as a sample of the target distribution $f(x)$.
- To ensure generated values accurately represent the target distribution $f(x)$ we must compare $f(x)$ to our easy distribution $g(x)$. That is, we must find a constant $c$ such that $f(x) \leq cg(x)$ for all $x$. The function $t(x)=cg(x)$ is referred to as the **majorizing function**. To find the smallest $c$ for which this holds (which minimizes number of rejects), you calculate $c^*=\sup_{x}\frac{f(x)}{g(x)}$.   
- The algorithm becomes:  
    1. Generate $Y$ with density $g(y)$.  
    2. Generate a standard uniform variable $U \sim U(0,1)$, independent of $Y$.  
    3. If $U \leq \frac{f(Y)}{cg(Y)}$, accept the value and return $X = Y$  
    4. Otherwise reject $Y$ and return to Step 1.
- The efficiency of this method is heavily dependent on the constant $c$. The total area under $f(x)$ is $1$, whereas the area under $t(x)$ is $c$. Therefore the probability of accepting on an arbitrary $Y$ is $1/c$. The tradeoff becomes keeping $c$ small, while keeping $g(x)$ simple enough to draw samples from.  
- **Thinning method**: To sample from a non-homogeneous Poisson distribution with rate $\lambda(t)$, we generate arrivals with some "peak" arrival rate $\lambda^*=\max_{t}\lambda(t)$.  Next, you generate "trial" arrivals using a standard, homogeneous Poisson process at the peak rate, and then accept an arrival at $t$ with probability $\lambda(t)/\lambda^*$.

### Markov Chain Monte Carlo

**Markov Chain Monte Carlo** (**MCMC**): instead of creating independent draws from a distribution, we construct a discrete time **[[5. Markov Chains|Markov chain]]** (fully defined by its transition probabilities) whose long-run stationary distribution is the target distribution. The idea is then to run the Markov chain, wait for it to settle, and then use its states as (dependent) draws from the target distribution.
- Advantage: capable of dealing with multi-dimensional/complicated target distributions.
- Disadvantage: the draws are dependent.

Required knowledge from Markov Chains: transition matrices, irreducibility, periodicity, ergodicity, stationary distribution, detailed balance equations.

**Discrete Metropolis–Hastings**: Start with an arbitrary irreducible transition matrix $Q$ (entries $q_{ij}$), then accept a proposed move $i \to j$ with probability $\alpha_{ij}$, staying put otherwise. This gives: $P_{ij} = q_{ij}\alpha_{ij}$ for $i\ne j$, and $P_{ii}=q_{ii}+\sum_{k\neq i}q_{ik}(1-\alpha_{ik})$. We want to pick suitable values for $\alpha_{ij}$ such that the detailed balance equations $\pi_{i}P_{ij}=\pi_{j}P_{ji}$ hold for some desired distribution $\pi_{j}=b_{j}/B$ where $B$ can be some unknown constant.

Derivation: 
1. First substitute $P_{ij} = q_{ij}\alpha_{ij}$, to get $\pi_{i}q_{ij}\alpha_{ij} = \pi_{j}q_{ji}\alpha_{ji}$.
2. Rearrange to get $\frac{\alpha_{ij}}{\alpha_{ji}} = \frac{\pi_{j}q_{ji}}{\pi_{i}q_{ij}}$. 
3. Each pair of probabilities $\alpha_{ij}$ and $\alpha_{ji}$ must match this ratio, but infinitely many such pairs exist, we need some criteria to decide which pairs are ideal.
4. Probabilities can be at most $1$, so in order to maximize the sample efficiency (minimize number of rejected moves), we ensure either $\alpha_{ij}$ or $\alpha_{ji}$ is set to $1$, and the other is set accordingly such that the ratio criteria is met. 
5. This gives $\alpha_{ij} = \min\left\{\frac{\pi_{j}q_{ji}}{\pi_{i}q_{ij}}, 1\right\}$.
6. One of the main benefits of Metropolis Hastings is that we may only know the distribution $\pi_{j}$ up to an unknown normalizing constant $B$, such that $\pi_{j}=b_{j}/B$, since this simply cancels out: $\alpha_{ij} = \min\left\{\frac{b_{j}q_{ji}/B}{b_{i}q_{ij}/B}, 1\right\} = \min\left\{\frac{b_{j}q_{ji}}{b_{i}q_{ij}}, 1\right\}$.
7. Furthermore, if you choose a symmetric proposal matrix $Q$ (meaning $q_{ij}=q_{ji}$ for all $i$ and $j$), then the proposal probabilities cancel out as well: $\alpha_{ij} = \min\left\{\frac{b_{j}}{b_{i}}, 1\right\}$.

The algorithm for creating dependent draws from $\pi_{j}=b_{j}/B$ for $j=1,\dots,N$ is:
1. Initialize: define arbitrary irreducible $Q$ of size $N \times N$, select arbitrary initial state $i$, and set counter to $n=0$.
2. Propose move: generate candidate state $j$ using probabilities from $q_{ij}$,.
3. Accept/Reject: generate random variable $U \sim U(0,1)$,
	- if $U < b_{j}q_{ji}/b_{i}q_{ij}$ we accept: $i \leftarrow j$.
	- otherwise we reject: $i \leftarrow i$.
4. Record and repeat: 
	- increment $n \leftarrow n+1$, 
	- record that current state $X_{n}=i$,
	- repeat from 2.

Metropolis-Hastings easily generalizes to continuous or multi-dimensional distributions.

**Gibbs Sampling**: unlike Metropolis-Hastings, Gibbs sampler finds a suitable transition matrix directly without correction. It constructs the transitional probabilities by sampling from one-dimensional conditional probability distributions, and every proposed move is accepted.

**Practical Notes**:
- Because successive states are dependent, to approximate i.i.d. draws one keeps only every $k$-th state ($X^k, X^{2k}, \dots$, e.g. $k=20$), the gaps reduce the dependence. 
- Convergence to the stationary distribution is guaranteed only in the limit (via ergodicity), so early states are typically discarded.
