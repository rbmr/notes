### Events

- **Experiment**: Any action whose outcome is subject to uncertainty.
- **Sample space** $S$: The set of all possible outcomes of an experiment.
	- Discrete if there are a finite or countably infinite number of outcomes.
	- Continuous if there is an uncountable number of outcomes.
- **Event** $A$: collection of outcomes, $A \subseteq S$. 
	- An event is called "simple" if it contains only one outcome, "compound" otherwise.
	- We say $A$ occurs, when an outcome belongs to $A$. 
- Events $A_1, A_2, \ldots$ are said to be **mutually exclusive** (or **disjoint**), if no two events have any outcomes in common. Formally, for all $i$ and $j$, if $i\neq j$ then $A_i \cap A_j = \emptyset$.

### Probability

- **Axioms of probability**: Let $S$ be a sample space of an experiment. A probability set function is a function that assigns a real value $P(A)$ to every event $A \subseteq S$ and satisfies the following three properties:
	1. $P(A) \ge 0$ for any event $A \subseteq S$.
	2. $P(S) = 1$
	3. For any countable collection $A_1, A_2, A_3, \dots$ of mutually exclusive events: 
		$$
		P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)
		$$
- The probability of the empty set is always zero: $P(\emptyset)=0$
- The **conditional probability** of an event $A$, given the event $B$, is defined by:
	$$
	P(A \mid B) = \frac{P(A \cap B)}{P(B)}
	$$
- Two events $A$ and $B$ are **mutually independent** if $P(A \cap B) = P(A) \cdot P(B)$.
- Events $A_1, \dots, A_n$ are **mutually independent** if for every subset $I \subseteq \{1, 2, \ldots, n\}$: 
	$$
	P\left(\bigcap_{i \in I} A_i\right) = \prod_{i \in I} P(A_i)
	$$
- If any pair $A_{i}$ and $A_{j}$ where $i \neq j$ from $A_{1}, \dots, A_{n}$ is mutually independent, this *does not* mean $A_{1}, \dots, A_{n}$ is mutually independent. 
	- Example: suppose we toss two fair coins, we define the following events: $A$ means the first coin is heads, $B$ means the second coin is heads, and $C$ means both coins are the same (both heads, or both tails). Then, each individual event has a probability of $\frac{1}{2}$, and each pair of events occurring has a probability of $\frac{1}{4}$, whereas all three events happening still has a probability of $\frac{1}{4}$, This shows $A, B, C$ are pairwise independent, but not mutually independent.
- **Bayes' rule**: gives a mathematical rule for inverting conditional probabilities.
	$$
	P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}
	$$
- **Law of Total Probability**: Let events $B_{1}, B_{2}, \ldots, B_{k}$ partition the sample space $S$ with $P(B_i) > 0$ for all $i$. Then for any event $A$:
	$$
	P(A) = \sum_{i=1}^k P(A \cap B_i) = \sum_{i=1}^k P(A \mid B_i)P(B_i)
	$$
