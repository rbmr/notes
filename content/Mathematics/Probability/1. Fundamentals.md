### Events

- **Experiment**: Any action whose outcome is subject to uncertainty.
- **Sample space** $S$: The set of all possible outcomes of an experiment.
	- Discrete if there are a finite or countably infinite number of outcomes.
	- Continuous if there is an uncountable number of outcomes.
- **Event** $A$: collection of outcomes, $A \subseteq S$. 
	- An event is called "simple" if it contains only one outcome, "compound" otherwise.
	- We say $A$ occurs, when an outcome belongs to $A$. 
- Events $A_1, A_2, \ldots$ are said to be **mutually exclusive** (or **disjoint**), if no two events have any outcomes in common. Formally, for all $i$ and $j$, if $i\neq j$ then $A_i \cap A_j = \emptyset$.

### Axioms of Probability

**Axioms of probability**: Let $S$ be a sample space of an experiment. A probability set function is a function that assigns a real value $P(A)$ to every event $A \subseteq S$ and satisfies the following three properties:
1. $P(A) \ge 0$ for any event $A \subseteq S$.
2. $P(S) = 1$
3. For any countable collection $A_1, A_2, A_3, \dots$ of mutually exclusive events: 
	$$
	P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)
	$$

Properties:
- $P(\emptyset)=0$
	1. axiom 3, $P(S) = P(S \cup \emptyset) = P(S) + P(\emptyset)$
	2. axiom 2, $1= 1  +P(\emptyset)$
	3. basic arithmetic, $P(\emptyset)=0 \quad \blacksquare$
- $P(A')=1-P(A)$, where $A'$ is the complement of $A$.
	1. definition of the complement, $A \cup A'=S$, and $A \cap A'=\emptyset$.
	2. axiom 3, $P(S)=P(A \cup A')=P(A)+P(A')$.
	3. axiom 2, $1=P(A)+P(A')$
	4. basic arithmetic, $P(A')=1-P(A) \quad \blacksquare$
- $P(A \cup B)=P(A)+P(B)-P(A \cap B)$
	1.  basic set theory, $A \cup B=A \cup(B \cap A')$
	2. axiom 3, $P(A \cup B)=P(A)+P(B \cap A')$
	3. basic set theory, $B = (A \cap B) \cup (B \cap A')$
	4. axiom 3, $P(B) = P(A \cap B) + P(B \cap A')$
	5. basic arithmetic, $P(B \cap A') = P(B) - P(A \cap B)$
	6. substitute 5 into 2, $P(A \cup B) = P(A) + P(B) - P(A \cap B) \quad \blacksquare$

### Conditional Probability

The **conditional probability** of an event $A$, given the event $B$, is defined by:
$$
P(A \mid B) = \frac{P(A \cap B)}{P(B)}
$$

Properties:
- $P(A \cap B) = P(A \mid B) \cdot P(B) = P(B \mid A) \cdot P(A)$
	- derived using simple arithmetic from definition of conditional probability. 
- For a fixed event $B$ with $P(B) >0$, $P(\ \cdot \mid B)$ satisfies the three axioms of probability.
	- Axiom 1: by the first axiom of probability $P(A \cap B) \ge 0$. Since we are given $P(B) > 0$, the ratio $\frac{P(A \cap B)}{P(B)} \ge 0$, consequently $P(A\mid B) \geq 0$ for all $A \subseteq S$.
	- Axiom 2: by definition $P(S \mid B)=\frac{P(S\cap B)}{P(B)}$. Since $B \subseteq S$, the intersection $S \cap B= B$. Therefore $P(S|B)=\frac{P(B)}{P(B)}=1$.
	- Axiom 3: Let $A_1, A_2, \dots$ be a countable collection of mutually exclusive events.
		1. by definition, $P\left(\bigcup_{i=1}^{\infty} A_i \mid B\right) = \frac{P\left(\left(\bigcup_{i=1}^{\infty} A_i\right) \cap B\right)}{P(B)}$
		2. by the distributive law of sets, $P\left(\bigcup_{i=1}^{\infty} A_i \mid B\right)=\frac{P\left(\bigcup_{i=1}^{\infty} (A_i \cap B)\right)}{P(B)}$
		3. since the $A_i$ events are mutually exclusive, the intersections $(A_i \cap B)$ are also mutually exclusive. Thus, by axiom 3, $P\left(\bigcup_{i=1}^{\infty} A_i \mid B\right)=\frac{\sum_{i=1}^{\infty} P(A_i \cap B)}{P(B)}$.
		4. by basic arithmetic, $P\left(\bigcup_{i=1}^{\infty} A_i \mid B\right)=\sum_{i=1}^{\infty} \frac{P(A_i \cap B)}{P(B)} = \sum_{i=1}^{\infty} P(A_i \mid B)$.
- **Bayes' Rule**: $P(A \mid B) = \frac{P(B \mid A)P(A)}{P(B)}$
	1. by the definition of conditional probability, $P(A \mid B) = \frac{P(A \cap B)}{P(B)}$
	2. similarly, $P(A \cap B) = P(B \cap A) = P(B \mid A)P(A)$. 
	3. substituting 2 into 1 gives $P(A \mid B) = \frac{P(B \mid A)P(A)}{P(B)}$
- **Law of Total Probability**: Let $B_1, B_2, \dots, B_n$ be a partition of the sample space $S$ (i.e., they are mutually exclusive and $\bigcup_{i=1}^n B_i = S$) such that $P(B_i) > 0$ for all $i$. Then. for any event $A$: $P(A) = \sum_{i=1}^n P(A \mid B_i)P(B_i)$.
	1. Any event $A$ can be written as $A = A \cap S = A \cap \left(\bigcup_{i=1}^n B_i\right)$.
	2. By the distributive law of sets, $A = \bigcup_{i=1}^n (A \cap B_i)$.
	3. Because $B_1, B_2, \dots, B_n$ are mutually exclusive, the intersections $(A \cap B_1), (A \cap B_2), \dots, (A \cap B_n)$ are also mutually exclusive.
	4. Applying Axiom 3 yields $P(A) = \sum_{i=1}^n P(A \cap B_i)$.
	5. Substituting $P(A \cap B_i) = P(A \mid B_i)P(B_i)$ results in $P(A) = \sum_{i=1}^n P(A \mid B_i)P(B_i)$.

### Independence

A collection of events $A_1, \dots, A_n$ are **mutually independent** if for every subset $I \subseteq \{1, 2, \ldots, n\}$: 
$$
P\left(\bigcap_{i \in I} A_i\right) = \prod_{i \in I} P(A_i)
$$


Properties:
- A pair of events $A$ and $B$ are **mutually independent** if and only if $P(A \cap B) = P(A) \cdot P(B)$.
	- For any $I \subseteq \{ {1,2,\dots,n} \}$, with $|I|<2$, the condition $P\left(\bigcap_{i \in I} A_i\right) = \prod_{i \in I} P(A_i)$ always holds regardless of $A_{i}$. Since $n=2$ in our case, the only condition that remains is $P(A \cap B) = P(A) \cdot P(B)$. 
- For any two events $A$ and $B$ with $P(A) > 0$ and $P(B) > 0$, the following three statements are logically equivalent:
	- $P(A \cap B)=P(A)P(B)$
	- $P(A \mid B) = P(A)$
    - $P(B \mid A) = P(B)$
	- Proof: 
		1. If, $P(A \cap B) = P(A)P(B)$, then $P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{P(A)P(B)}{P(B)} = P(A)$
		2. If $P(A \mid B) = P(A)$, then $\frac{P(A \cap B)}{P(B)} = P(A) \implies P(A \cap B) = P(A)P(B)$. This gives $P(B \mid A) = \frac{P(A \cap B)}{P(A)} = \frac{P(A)P(B)}{P(A)} = P(B)$.
		3. If $P(B \mid A) = P(B)$, then $\frac{P(A \cap B)}{P(A)} = P(B) \implies P(A \cap B)=P(A)P(B)$.
- If any pair $A_{i}$ and $A_{j}$ where $i \neq j$ from $A_{1}, \dots, A_{n}$ is mutually independent, this *does not* mean $A_{1}, \dots, A_{n}$ is mutually independent. 
	- Example: suppose we toss two fair coins, we define the following events: $A$ means the first coin is heads, $B$ means the second coin is heads, and $C$ means both coins are the same (both heads, or both tails). Then, each individual event occurs with probability $\frac{1}{2}$, and each pair of events occurs with probability $\frac{1}{4}$, but all three events happening simultaneously occurs with probability $\frac{1}{4}$. This shows $A, B, C$ are pairwise independent, but not mutually independent.
- For any two events $A$ and $B$ with $P(A) > 0$ and $P(B) > 0$, the events cannot be both mutually exclusive and independent.
	1. Suppose, for the sake of contradiction, that $A$ and $B$ are _both_ mutually exclusive and independent.
	2. Because they are mutually exclusive, $P(A \cap B) = P(\emptyset)= 0$.
	3. Because they are independent, $P(A \cap B) = P(A)P(B)$.
	4. Equating the two yields $P(A)P(B) = 0$.
	5. For the product to be zero, either $P(A) = 0$ or $P(B) = 0$.
	6. However, this directly contradicts our premise that $P(A) > 0$ and $P(B) > 0$. Therefore, $A$ and $B$ cannot be both mutually exclusive and independent.
