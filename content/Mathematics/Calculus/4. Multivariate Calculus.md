### Introduction

Multivariate calculus studies functions of several variables. The core ideas of [[1. Univariate Calculus]] including limits, derivatives, and integrals, still apply, but the extra dimensions change their character. To reduce the amount of duplicate information, not all of the terms from univariate calculus are translated to multivariate calculus, especially if this translation is trivial.

### From a line to a space

- A **scalar field** (scalar-valued function) is a function $f: \mathbb{R}^n \to \mathbb{R}$ (where $n \geq 1$) that maps a point $\mathbf{x} = (x_1, \dots, x_n)$ to a single real number.
- A **vector field** (vector-valued function) is a function $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ (where $n\geq 1$ and $m>1$) that maps a point to an $m$-dimensional vector. 
	- A vector field $\mathbf{F}(\mathbf{x})$ can be defined fully using its $m$ scalar-valued component functions $F_{i}:\mathbb{R}^n \to \mathbb{R}$, as: $\mathbf{F}(\mathbf{x}) = (F_1(\mathbf{x}), \dots, F_m(\mathbf{x}))$.
- **Distance** in $\mathbb{R}^n$ is measured with the **Euclidean norm** $\|\mathbf{x} - \mathbf{a}\| = \sqrt{\sum_{i=1}^n (x_i - a_i)^2}$.
	- This is the higher dimensional equivalent of $|x-a|$.
- An **open ball** $B_\delta(\mathbf{a}) = \{\mathbf{x} : \|\mathbf{x} - \mathbf{a}\| < \delta\}$ is the set of all points $\mathbf{x}$ less than some distance $\delta$ from $\mathbf{a}$.
	-  This is the higher dimensional equivalent of the open interval $(a - \delta,\, a + \delta)$.
- A set $X \subseteq \mathbb{R}^n$ is **open** if for every point $x \in X$, there exists a radius $r > 0$ such that the open ball $B_r(x) \subseteq X$. Intuitively: from any point in the set you can move some small distance in any direction without leaving the set.
- A set $X \subseteq \mathbb{R}^n$ is **closed** if its complement, $\mathbb{R}^n \setminus X$, is an open set. Intuitively, the set contains its own boundary.
- The **interior** of a set $X$, denoted $\text{int}(X)$, is the largest open set contained within $X$ (the set $X$ with its boundary points removed).
- A set $X \subseteq \mathbb{R}^n$ is **bounded** if it can be contained within a ball of finite radius. Formally, there exists a real number $M > 0$ such that $\|x\| < M$ for all $x \in X$. 
- A set $X \subseteq \mathbb{R}^n$ is **unbounded** if it is not bounded.
- A set $X \subseteq \mathbb{R}^n$ is **compact** if and only if it is both closed and bounded.
- Relation to the 1-dimensional case: the open interval $(a,b)$ is an open set, the closed interval $[a,b]$ is a closed set, and both are bounded. $[a,b]$ is closed and bounded and thus compact, and $[a, \infty)$ is closed but not bounded and thus not compact.

### Limits and continuity

- Core Difference: On the real number line, you can only approach a point $a$ from two sides, so a limit exists when the left-limit and right-limit agree. In $\mathbb{R}^n$ with $n \ge 2$ there are infinitely many paths along which $\mathbf{x}$ can approach $\mathbf{a}$.
- **Definition of the Limit**: $\lim_{\mathbf{x} \to \mathbf{a}} f(\mathbf{x}) = L$ if for every $\epsilon > 0$ there exists a $\delta > 0$ such that for every $\mathbf{x}$ in the domain of $f$,
	$$
	0 < \|\mathbf{x} - \mathbf{a}\| < \delta \;\implies\; |f(\mathbf{x}) - L| < \epsilon.
	$$
	- This is exactly the 1D $\epsilon$–$\delta$ definition with the punctured interval $0 < |x - a| < \delta$ replaced by this punctured open ball $0 < ||\mathbf{x}-\mathbf{a}||<\delta$.
	- Similarly, the definition of the **limit for a vector field** $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ with limit $\mathbf{L}$, is formed by replacing $|f(\mathbf{x}) - L|$ by the norm $\|\mathbf{F}(\mathbf{x}) - \mathbf{L}\|$.
- The limit of a vector field $\mathbf{F}(\mathbf{x})$ exists and equals the vector $\mathbf{L} = (L_1, \dots, L_m)$ if and only if the limit of every individual scalar component function $F_i(\mathbf{x})$ exists and equals $L_i$.
- **Limit along a path**: Let $I \subseteq \mathbb{R}$ be an open interval containing $0$. A path is a continuous curve $\mathbf{r}: I \to \mathbb{R}^n$ parameterized by a single variable $t$, such that $\mathbf{r}(0) = \mathbf{a}$. The limit along such a path collapses entirely into a univariate calculus problem: $\lim_{t \to 0} f(\mathbf{r}(t))$.
- The multivariate limit $\lim_{\mathbf{x} \to \mathbf{a}} f(\mathbf{x}) = L$ exists if and only if the 1D limit $\lim_{t \to 0} f(\mathbf{r}(t)) = L$ for every possible continuous path $\mathbf{r}(t)$ defined on some interval $I$ passing through $\mathbf{a}$.
	- This makes multivariate limits easy to *disprove* (only need to find two paths that yield different limits), but harder to *prove*.
- $f$ is **continuous at** $\mathbf{a}$ if $f(\mathbf{a})$ is defined and $\lim_{\mathbf{x} \to \mathbf{a}} f(\mathbf{x}) = f(\mathbf{a})$ 
	- This is the same definition as in 1D, but now with the ball-based limit.

### Directional Derivatives

- A **partial derivative** measures the rate of change of $f$ as *one* variable varies while the others are held fixed:
	$$
	\frac{\partial f}{\partial x_i}(\mathbf{a}) = \lim_{h \to 0} \frac{f(\mathbf{a} + h\,\mathbf{e}_i) - f(\mathbf{a})}{h}
	$$
	where $\mathbf{e}_i$ is the $i$-th standard basis vector. 
- Note: The partial derivative is an ordinary 1-dimensional derivative taken along the $x_i$-axis, so every rule from [[1. Univariate Calculus]] applies to it.
- The **gradient** is the vector field defined by combining all $n$ partial derivatives into a single vector:
	$$
	\nabla f(\mathbf{a}) = \left[ \frac{\partial f}{\partial x_1}(\mathbf{a}), \; \dots, \; \frac{\partial f}{\partial x_n}(\mathbf{a}) \right]^\top
	$$
- For a unit vector $\mathbf{u}$, the **directional derivative** of $f$ along $\mathbf{u}$ is defined as:
	$$
	D_{\mathbf{u}} f(\mathbf{a}) = \lim_{h \to 0} \frac{f(\mathbf{a} + h\mathbf{u}) - f(\mathbf{a})}{h}
	$$
- Note: For $n \geq 2$ dimensions, there are infinitely many possible directional derivatives whereas in 1-dimension there were only two (left and right).

	$$
	D_{\mathbf{u}} f(0,0) = \lim_{h \to 0} \frac{f(hu_1, hu_2) - f(0,0)}{h}  = \lim_{h \to 0} \frac{h u_1^4 u_2^2}{(h^2 u_1^4 + u_2^2)^2}

	If $u_2 \neq 0$, then as $h \to 0$, the numerator approaches 0 while the denominator approaches $u_2^4 > 0$, making the limit 0. If $u_2 = 0$, the function evaluates to $0$ for all $h \neq 0$, so the limit is also $0$. Thus, all directional derivatives (including partial derivatives) exist and equal $0$ at the origin.

	$$
	Because the limit along this path is $\frac{1}{4}$, but $f(0,0) = 0$. Therefore, $f$ is not continuous at the origin.
4.  This shows that the existence of all directional derivatives does not guarantee continuity.

Differentiability

- $f$ is **differentiable at** $\mathbf{a}$ if it is well-approximated by its tangent plane $f(\mathbf{a}) + \nabla f(\mathbf{a})^\top \mathbf{h}$ near $\mathbf{a}$. Formally, given the approximation error $e(\mathbf{h}) = f(\mathbf{a} + \mathbf{h}) - f(\mathbf{a}) - \nabla f(\mathbf{a})^\top \mathbf{h}$, $f$ is differentiable at $\mathbf{a}$ if the absolute approximation error shrinks strictly faster than the step size $\|\mathbf{h}\|$ as $\mathbf{h} \to \mathbf{0}$, that is:
	$$
	\lim_{\mathbf{h} \to \mathbf{0}} \frac{|e(\mathbf{h})|}{\|\mathbf{h}\|} = 0.
	$$
- $f$ is **differentiable on** an open set $U \subseteq \mathbb{R}^n$ if it is differentiable at every point $\mathbf{a} \in U$.

Core Theorems 

- If $f$ is differentiable at $\mathbf{a}$, then it is continuous at $\mathbf{a}$. 
	- The converse is not true in general: continuity does not imply differentiability. 
- Sufficient condition: if all partial derivatives of $f$ exist *and are continuous* in an open set containing $\mathbf{a}$, then $f$ is differentiable at $\mathbf{a}$.
	- Note: $f$ is called **continuously differentiable** on an open set $U$ if all its partial derivatives exist and are continuous on $U$. By the sufficient condition, continuously differentiable functions are differentiable.
- If $f$ is differentiable at $\mathbf{a}$, then for every unit vector $\mathbf{u} \in \mathbb{R}^n$ (with $\|\mathbf{u}\| = 1$) the directional derivative exists and equals $D_{\mathbf{u}} f(\mathbf{a}) = \nabla f(\mathbf{a})^\top \mathbf{u}$. 
	- Note: the converse is generally not true, even if $D_{\mathbf{u}} f(\mathbf{a})$ exists for every unit vector $\mathbf{u}$, $f$ is not guaranteed to be differentiable at $\mathbf{a}$.
- If $D_{\mathbf{u}} f(\mathbf{a}) = \nabla f(\mathbf{a})^\top \mathbf{u}$, then:
	- $\nabla f(\mathbf{a})$ points in the direction of **steepest ascent**.
	- $-\nabla f(\mathbf{a})$ points in the direction of **steepest descent**.
	- $\|\nabla f(\mathbf{a})\|$ is the maximal rate of increase at $\mathbf{a}$.
	- $\nabla f(\mathbf{a})$ is orthogonal to the level set $\{\mathbf{x} : f(\mathbf{x}) = f(\mathbf{a})\}$ passing through $\mathbf{a}$.

### The Jacobian

- The **Jacobian** of a vector field $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ with component functions $F_1, \dots, F_m$ at a point $\mathbf{a}$, denoted $J_{\mathbf{F}}(\mathbf{a})$, is the $m \times n$ matrix collecting all first-order partial derivatives:
	$$
	J_{\mathbf{F}}(\mathbf{a}) =
	\begin{bmatrix}
	\frac{\partial F_1}{\partial x_1}(\mathbf{a}) & \cdots & \frac{\partial F_1}{\partial x_n}(\mathbf{a}) \\
	\vdots & \ddots & \vdots \\
	\frac{\partial F_m}{\partial x_1}(\mathbf{a}) & \cdots & \frac{\partial F_m}{\partial x_n}(\mathbf{a})
	\end{bmatrix}
	$$
	Each row $i$ corresponds to the gradient of the $i$-th component function $\nabla F_i(\mathbf{a})^\top$.
- The Jacobian is the matrix of the best linear approximation of $\mathbf{F}$ near $\mathbf{a}$:
	$$
	\mathbf{F}(\mathbf{a} + \mathbf{h}) \approx \mathbf{F}(\mathbf{a}) + J_{\mathbf{F}}(\mathbf{a})\,\mathbf{h}
	$$
- The definition of differentiability for vector fields carries over from scalar fields by replacing $\nabla f(\mathbf{a})^\top \mathbf{h}$ with $J_{\mathbf{F}}(\mathbf{a})\mathbf{h}$ and the absolute approximation error $|e(\mathbf{h})|$ with the norm $\|\mathbf{e}(\mathbf{h})\|$.
- **Chain rule**: if $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ is differentiable at $\mathbf{a}$ and $\mathbf{G}: \mathbb{R}^m \to \mathbb{R}^p$ is differentiable at $\mathbf{F}(\mathbf{a})$, then:
	$$
	J_{\mathbf{G} \circ \mathbf{F}}(\mathbf{a}) = J_{\mathbf{G}}(\mathbf{F}(\mathbf{a}))\; J_{\mathbf{F}}(\mathbf{a})
	$$
	Intuition: Composing maps multiplies their Jacobians, the linear approximation of a composition is the composition of the linear approximations. This generalizes the univariate chain rule $(g \circ f)'(x) = g'(f(x)) \cdot f'(x)$, with matrix multiplication replacing the product of numbers.
- The **Jacobian determinant** of a map $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^n$ (only defined for $m = n$) is $\det J_{\mathbf{F}}(\mathbf{a})$. It is the local volume scaling factor of the map: a small region with volume $V$ around $\mathbf{a}$ is mapped to a region with volume approximately $|\det J_{\mathbf{F}}(\mathbf{a})| \cdot V$, and the sign of the determinant indicates whether the map preserves or flips orientation.
	- In 1 dimension this is the familiar stretching factor $f'(a)$: lengths near $a$ get scaled by $|f'(a)|$.
	- This is why the Jacobian determinant appears when changing variables in multiple integrals: it plays the role of $du = g'(x)\,dx$ in the substitution rule from [[1. Univariate Calculus]].

### The Hessian

- The **Hessian** of a scalar field $f: \mathbb{R}^n \to \mathbb{R}$ at $\mathbf{a}$, denoted $\nabla^2 f(\mathbf{a})$, is the $n \times n$ matrix collecting all second-order partial derivatives:
	$$
	[\nabla^2 f(\mathbf{a})]_{ij} = \frac{\partial^2 f}{\partial x_i \, \partial x_j}(\mathbf{a})
	$$
- In 1 dimension the Hessian is the $1 \times 1$ matrix $[f''(a)]$: the Hessian plays the role of the second derivative, describing the local curvature of $f$.
- Relation to the Jacobian: the gradient is itself a vector field $\nabla f: \mathbb{R}^n \to \mathbb{R}^n$, and the Hessian is its Jacobian: $\nabla^2 f(\mathbf{a}) = J_{\nabla f}(\mathbf{a})$. Differentiating once gives the gradient; differentiating the gradient again gives the Hessian — just as $f''$ is the derivative of $f'$.
- $f$ is **twice continuously differentiable** on an open set $U$ if all its second-order partial derivatives exist and are continuous on $U$.
- **Clairaut's (Schwarz's) Theorem**: if the second-order partial derivatives of $f$ are continuous at $\mathbf{a}$, then the order of differentiation does not matter:
	$$
	\frac{\partial^2 f}{\partial x_i \, \partial x_j}(\mathbf{a}) = \frac{\partial^2 f}{\partial x_j \, \partial x_i}(\mathbf{a})
	$$
	Consequently, the Hessian of a twice continuously differentiable function is a symmetric matrix.

### Taylor's Theorem

- Recall the Mean Value Theorem from [[1. Univariate Calculus]]: it turns the linear approximation $f(x+p) \approx f(x) + f'(x)p$ into an *exact* statement, by evaluating the derivative at some intermediate point instead of at $x$. Taylor's theorem does the same one order higher: the first two terms are exact, and all remaining error is captured by a second-order term evaluated at an intermediate point. (The univariate version, for arbitrary orders, is covered in [[3. Series#Taylor Series]].)
- **Taylor's Theorem** (second-order, mean value form): Let $f:\mathbb{R}^n \rightarrow \mathbb{R}$ be twice continuously differentiable, and let $\mathbf{x}, \mathbf{p} \in \mathbb{R}^n$. Then, there exists a $t \in (0,1)$ such that:
	$$
	f(\mathbf{x}+\mathbf{p}) = f(\mathbf{x}) + \nabla f(\mathbf{x})^\top \mathbf{p} + \frac{1}{2}\mathbf{p}^\top \nabla^2 f(\mathbf{x}+t\mathbf{p})\,\mathbf{p}
	$$
	- Note that $\mathbf{x} + t\mathbf{p}$ with $t \in (0,1)$ is a point on the line segment strictly between $\mathbf{x}$ and $\mathbf{x}+\mathbf{p}$, mirroring the intermediate point $c \in (a,b)$ of the Mean Value Theorem.
- Evaluating the Hessian at $\mathbf{x}$ instead of the (unknown) intermediate point yields the **second-order Taylor approximation** $f(\mathbf{x}+\mathbf{p}) \approx f(\mathbf{x}) + \nabla f(\mathbf{x})^\top \mathbf{p} + \frac{1}{2}\mathbf{p}^\top \nabla^2 f(\mathbf{x})\mathbf{p}$; dropping the quadratic term yields the **first-order Taylor approximation** $f(\mathbf{x}+\mathbf{p}) \approx f(\mathbf{x}) + \nabla f(\mathbf{x})^\top \mathbf{p}$ (the tangent plane approximation from the differentiability definition above).
- Taylor's theorem can also be stated for the gradient itself (integral form): under the same conditions,
	$$
	\nabla f(\mathbf{x}+\mathbf{p}) = \nabla f(\mathbf{x}) + \int_0^1 \nabla^2 f(\mathbf{x}+t\mathbf{p})\,\mathbf{p} \; dt
	$$
	This is the Fundamental Theorem of Calculus applied to each component of the gradient along the segment from $\mathbf{x}$ to $\mathbf{x}+\mathbf{p}$.

### Extreme values

The definitions from the extreme values section of [[1. Univariate Calculus]] carry over to scalar fields $f: D \to \mathbb{R}$ with $D \subseteq \mathbb{R}^n$ essentially unchanged: **(global and local) maximizers/minimizers**, **maxima/minima**, **extremizers/extrema**, and **suprema/infima** are defined identically, where for the local versions we only replace the interval condition $|x - c| < \epsilon$ with the open ball condition $\|\mathbf{x} - \mathbf{c}\| < \epsilon$ (i.e. $\mathbf{x} \in B_\epsilon(\mathbf{c})$).

First-order results (positive (semi)definiteness $\succeq, \succ$ is defined in [[5. Matrix Calculation Rules Cheatsheet]]):

- A **stationary point** of $f$ is a point $\mathbf{a}$ where $\nabla f(\mathbf{a}) = \mathbf{0}$ (the multivariate analogue of a critical number with an existing derivative).
- **Fermat's Theorem**: Let $\mathbf{a}$ be a local maximizer or minimizer of $f$, and assume $f$ is continuously differentiable in an open set containing $\mathbf{a}$. Then $\nabla f(\mathbf{a}) = \mathbf{0}$.
	- Intuition: along each coordinate axis, $\mathbf{a}$ is a local extremizer of a univariate function, so by the univariate Fermat's theorem every partial derivative vanishes.
	- The converse is not true: a stationary point need not be an extremizer (see saddle points below).

Second-order results (let $f$ be twice continuously differentiable in an open set $S$ containing $\mathbf{a}$):

- **Second-Order Necessary Condition**: if $\mathbf{a} \in S$ is a local minimizer of $f$, then $\nabla f(\mathbf{a}) = \mathbf{0}$ and $\nabla^2 f(\mathbf{a}) \succeq 0$.
- **Second-Order Sufficient Condition**: if $\nabla f(\mathbf{a}) = \mathbf{0}$ and $\nabla^2 f(\mathbf{a}) \succ 0$, then $\mathbf{a}$ is a local minimizer of $f$.
- For maximizers, apply the statements to $-f$: the conditions become $\nabla^2 f(\mathbf{a}) \preceq 0$ and $\prec 0$ respectively.
- In 1 dimension these reduce to the second derivative test: $f''(a) \geq 0$ is necessary, $f''(a) > 0$ is sufficient.
- Intuition via [[#Taylor's Theorem|Taylor's theorem]]: near a stationary point, $f(\mathbf{a}+\mathbf{p}) \approx f(\mathbf{a}) + \frac{1}{2}\mathbf{p}^\top \nabla^2 f(\mathbf{a})\mathbf{p}$, so the sign of the quadratic form decides whether nearby values are above or below $f(\mathbf{a})$.
- Mind the gap between the necessary and the sufficient condition: if the Hessian at a stationary point is positive semidefinite but not positive definite, the test is inconclusive. Example: $f(x) = x^3$ and $f(x)=x^4$ both have $f'(0) = 0$ and $f''(0) = 0$, but only the latter has a minimizer at $0$.
- A **saddle point** is a stationary point that is neither a local minimizer nor a local maximizer. This happens for example when the Hessian is indefinite (has both positive and negative eigenvalues): $f$ curves up in some directions and down in others, like $f(x,y) = x^2 - y^2$ at the origin.

Existence:

- **Extreme Value Theorem** (also known as **Weierstrass' Theorem**): Let $X \subseteq \mathbb{R}^n$ be a compact (closed and bounded) non-empty set, and let $f:X \rightarrow \mathbb{R}$ be a continuous function. Then $f$ has a global minimizer and a global maximizer on $X$. This generalizes the Extreme Value Theorem from [[1. Univariate Calculus]]: the closed interval $[a,b]$ is exactly a compact subset of $\mathbb{R}$.
