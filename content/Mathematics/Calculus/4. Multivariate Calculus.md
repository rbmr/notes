### Introduction

Multivariate calculus studies functions of several variables. The core ideas of [[1. Univariate Calculus]] including limits, derivatives, and integrals, still apply, but the extra dimensions change their character. To reduce the amount of duplicate information, not all of the terms from univariate calculus are translated to multivariate calculus, especially if this translation is trivial.

### From a line to a space

- A **scalar field** (scalar-valued function) is a function $f: \mathbb{R}^n \to \mathbb{R}$ (where $n \geq 1$) that maps a point $\mathbf{x} = (x_1, \dots, x_n)$ to a single real number.
- A **vector field** (vector-valued function) is a function $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ (where $n\geq 1$ and $m>1$) that maps a point to an $m$-dimensional vector. 
	- A vector field $\mathbf{F}(\mathbf{x})$ can be defined fully using its $m$ scalar-valued component functions $F_{i}:\mathbb{R}^n \to \mathbb{R}$, as: $\mathbf{F}(\mathbf{x}) = (F_1(\mathbf{x}), \dots, F_m(\mathbf{x}))$.
- **Distance** in $\mathbb{R}^n$ is measured with the **Euclidean norm** $\|\mathbf{x} - \mathbf{a}\| = \sqrt{\sum_{i=1}^n (x_i - a_i)^2}$.
	- This is the higher dimensional equivalent of $|x-a|$.
- An **open ball** $B_\delta(\mathbf{a}) = \{\mathbf{x} : \|\mathbf{x} - \mathbf{a}\| < \delta\}$ is the set of all points $\mathbf{x}$ less than some distance $\delta$ from $\mathbf{a}$.
	-  This is the higher dimensional equivalent of the open interval $(a - \delta,\, a + \delta)$.
- A set $X \subseteq \mathbb{R}^n$ is **open** if for every point $x \in X$, there exists a radius $r > 0$ such that the open ball $B_r(x) \subseteq X$. Intuitively: from any point in the set you can move some small distance in any direction without leaving the set.
- A set $X \subseteq \mathbb{R}^n$ is **closed** if its complement, $\mathbb{R}^n \setminus X$, is an open set. Intuitively, the set contains its own boundary.
- The **interior** of a set $X$, denoted $\text{int}(X)$, is the largest open set contained within $X$ (the set $X$ with its boundary points removed).
- A set $X \subseteq \mathbb{R}^n$ is **bounded** if it can be contained within a ball of finite radius. Formally, there exists a real number $M > 0$ such that $\|x\| < M$ for all $x \in X$. 
- A set $X \subseteq \mathbb{R}^n$ is **unbounded** if it is not bounded.
- A set $X \subseteq \mathbb{R}^n$ is **compact** if and only if it is both closed and bounded.
- Relation to the 1-dimensional case: the open interval $(a,b)$ is an open set, the closed interval $[a,b]$ is a closed set, and both are bounded. $[a,b]$ is closed and bounded and thus compact, and $[a, \infty)$ is closed but not bounded and thus not compact.

### Limits and continuity

- Core Difference: On the real number line, you can only approach a point $a$ from two sides, so a limit exists when the left-limit and right-limit agree. In $\mathbb{R}^n$ with $n \ge 2$ there are infinitely many paths along which $\mathbf{x}$ can approach $\mathbf{a}$.
- **Definition of the Limit**: $\lim_{\mathbf{x} \to \mathbf{a}} f(\mathbf{x}) = L$ if for every $\epsilon > 0$ there exists a $\delta > 0$ such that for every $\mathbf{x}$ in the domain of $f$,
	$$
	0 < \|\mathbf{x} - \mathbf{a}\| < \delta \;\implies\; |f(\mathbf{x}) - L| < \epsilon.
	$$
	- This is exactly the 1D $\epsilon$–$\delta$ definition with the punctured interval $0 < |x - a| < \delta$ replaced by this punctured open ball $0 < ||\mathbf{x}-\mathbf{a}||<\delta$.
	- Similarly, the definition of the **limit for a vector field** $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ with limit $\mathbf{L}$, is formed by replacing $|f(\mathbf{x}) - L|$ by the norm $\|\mathbf{F}(\mathbf{x}) - \mathbf{L}\|$.
- The limit of a vector field $\mathbf{F}(\mathbf{x})$ exists and equals the vector $\mathbf{L} = (L_1, \dots, L_m)$ if and only if the limit of every individual scalar component function $F_i(\mathbf{x})$ exists and equals $L_i$.
- **Limit along a path**: Let $I \subseteq \mathbb{R}$ be an open interval containing $0$. A path is a continuous curve $\mathbf{r}: I \to \mathbb{R}^n$ parameterized by a single variable $t$, such that $\mathbf{r}(0) = \mathbf{a}$. The limit along such a path collapses entirely into a univariate calculus problem: $\lim_{t \to 0} f(\mathbf{r}(t))$.
- The multivariate limit $\lim_{\mathbf{x} \to \mathbf{a}} f(\mathbf{x}) = L$ exists if and only if the 1D limit $\lim_{t \to 0} f(\mathbf{r}(t)) = L$ for every possible continuous path $\mathbf{r}(t)$ defined on some interval $I$ passing through $\mathbf{a}$.
	- This makes multivariate limits easy to *disprove* (only need to find two paths that yield different limits), but harder to *prove*.
- $f$ is **continuous at** $\mathbf{a}$ if $f(\mathbf{a})$ is defined and $\lim_{\mathbf{x} \to \mathbf{a}} f(\mathbf{x}) = f(\mathbf{a})$ 
	- This is the same definition as in 1D, but now with the ball-based limit.

### Directional Derivatives

- A **partial derivative** measures the rate of change of $f$ as *one* variable varies while the others are held fixed:
	$$
	\frac{\partial f}{\partial x_i}(\mathbf{a}) = \lim_{h \to 0} \frac{f(\mathbf{a} + h\,\mathbf{e}_i) - f(\mathbf{a})}{h}
	$$
	where $\mathbf{e}_i$ is the $i$-th standard basis vector. 
- Note: The partial derivative is an ordinary 1-dimensional derivative taken along the $x_i$-axis, so every rule from [[1. Univariate Calculus]] applies to it.
- The **gradient** is the vector field defined by combining all $n$ partial derivatives into a single vector:
	$$
	\nabla f(\mathbf{a}) = \left[ \frac{\partial f}{\partial x_1}(\mathbf{a}), \; \dots, \; \frac{\partial f}{\partial x_n}(\mathbf{a}) \right]^\top
	$$
- For a unit vector $\mathbf{u}$, the **directional derivative** of $f$ along $\mathbf{u}$ is defined as:
	$$
	D_{\mathbf{u}} f(\mathbf{a}) = \lim_{h \to 0} \frac{f(\mathbf{a} + h\mathbf{u}) - f(\mathbf{a})}{h}
	$$
- Note: For $n \geq 2$ dimensions, there are infinitely many possible directional derivatives whereas in 1-dimension there were only two (left and right).

### Differentiability

In 1-dimensional calculus, if a derivative exists at a point, then the function is differentiable and thus continuous at that point. In multivariate calculus the existence of all directional derivatives (including partial derivatives) is not sufficient to guarantee that $f$ is continuous at $\mathbf{a}$.  

Proof by example:
1. Consider $f(x,y) = \frac{x^4y^2}{(x^4+y^2)^2}$ for $(x,y) \neq (0,0)$, and $f(0,0) = 0$. 
2. Let $\mathbf{u} = (u_1, u_2)$ be any unit vector, then the directional derivative at the origin is:
	$$
	D_{\mathbf{u}} f(0,0) = \lim_{h \to 0} \frac{f(hu_1, hu_2) - f(0,0)}{h}  = \lim_{h \to 0} \frac{h u_1^4 u_2^2}{(h^2 u_1^4 + u_2^2)^2}
	$$
	If $u_2 \neq 0$, then as $h \to 0$, the numerator approaches 0 while the denominator approaches $u_2^4 > 0$, making the limit 0. If $u_2 = 0$, the function evaluates to $0$ for all $h \neq 0$, so the limit is also $0$. Thus, all directional derivatives (including partial derivatives) exist and equal $0$ at the origin.
3. Consider approaching the origin along the parabolic path $\mathbf{r}(t) = (t, t^2)$. Evaluating the function along this path gives: 
	$$
	f(t, t^2) = \frac{t^4(t^2)^2}{(t^4+(t^2)^2)^2} = \frac{t^8}{(2t^4)^2} = \frac{t^8}{4t^8} \implies \lim_{ t \to 0 }f(t,t^2)=\frac{1}{4}
	$$
	Because the limit along this path is $\frac{1}{4}$, but $f(0,0) = 0$. Therefore, $f$ is not continuous at the origin.
4.  This shows that the existence of all directional derivatives does not guarantee continuity.

Differentiability

- $f$ is **differentiable at** $\mathbf{a}$ if it is well-approximated by its tangent plane $f(\mathbf{a}) + \nabla f(\mathbf{a})^\top \mathbf{h}$ near $\mathbf{a}$. Formally, given the approximation error $e(\mathbf{h}) = f(\mathbf{a} + \mathbf{h}) - f(\mathbf{a}) - \nabla f(\mathbf{a})^\top \mathbf{h}$, $f$ is differentiable at $\mathbf{a}$ if the absolute approximation error shrinks strictly faster than the step size $\|\mathbf{h}\|$ as $\mathbf{h} \to \mathbf{0}$, that is:
	$$
	\lim_{\mathbf{h} \to \mathbf{0}} \frac{|e(\mathbf{h})|}{\|\mathbf{h}\|} = 0.
	$$
- $f$ is **differentiable on** an open set $U \subseteq \mathbb{R}^n$ if it is differentiable at every point $\mathbf{a} \in U$.

Core Theorems 

- If $f$ is differentiable at $\mathbf{a}$, then it is continuous at $\mathbf{a}$. 
	- The converse is not true in general: continuity does not imply differentiability. 
- Sufficient condition: if all partial derivatives of $f$ exist *and are continuous* in an open set containing $\mathbf{a}$, then $f$ is differentiable at $\mathbf{a}$.
	- Note: $f$ is called **continuously differentiable** on an open set $U$ if all its partial derivatives exist and are continuous on $U$. By the sufficient condition, continuously differentiable functions are differentiable.
- If $f$ is differentiable at $\mathbf{a}$, then for every unit vector $\mathbf{u} \in \mathbb{R}^n$ (with $\|\mathbf{u}\| = 1$) the directional derivative exists and equals $D_{\mathbf{u}} f(\mathbf{a}) = \nabla f(\mathbf{a})^\top \mathbf{u}$. 
	- Note: the converse is generally not true, even if $D_{\mathbf{u}} f(\mathbf{a})$ exists for every unit vector $\mathbf{u}$, $f$ is not guaranteed to be differentiable at $\mathbf{a}$.
- If $D_{\mathbf{u}} f(\mathbf{a}) = \nabla f(\mathbf{a})^\top \mathbf{u}$, then:
	- $\nabla f(\mathbf{a})$ points in the direction of **steepest ascent**.
	- $-\nabla f(\mathbf{a})$ points in the direction of **steepest descent**.
	- $\|\nabla f(\mathbf{a})\|$ is the maximal rate of increase at $\mathbf{a}$.
	- $\nabla f(\mathbf{a})$ is orthogonal to the level set $\{\mathbf{x} : f(\mathbf{x}) = f(\mathbf{a})\}$ passing through $\mathbf{a}$.
