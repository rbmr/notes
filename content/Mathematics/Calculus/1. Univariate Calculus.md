### Interval Notation

- **Interval Notation** is a shorthand way to describe continuous subsets of the set of real numbers $\mathbb{R}$.
- To define an interval, you simply define its endpoints (upper and lower bound). Each endpoint can either be closed (included), open (excluded), or infinite (no bound).

| **Lower \ Upper** | **Closed (Included)**                                       | **Open (Excluded)**                                      | **Infinite (No Bound)**                                                 |
| ----------------- | ----------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------------- |
| **Closed**        | $[a, b]$<br><br>$\{x \in \mathbb{R} \mid a \leq x \leq b\}$ | $[a, b)$<br><br>$\{x \in \mathbb{R} \mid a \leq x < b\}$ | $[a, \infty)$<br><br>$\{x \in \mathbb{R} \mid x \geq a\}$               |
| **Open**          | $(a, b]$<br><br>$\{x \in \mathbb{R} \mid a < x \leq b\}$    | $(a, b)$<br><br>$\{x \in \mathbb{R} \mid a < x < b\}$    | $(a, \infty)$<br><br>$\{x \in \mathbb{R} \mid x > a\}$                  |
| **Infinite**      | $(-\infty, b]$<br><br>$\{x \in \mathbb{R} \mid x \leq b\}$  | $(-\infty, b)$<br><br>$\{x \in \mathbb{R} \mid x < b\}$  | $(-\infty, \infty)$<br><br>$\{x \in \mathbb{R} \mid x \in \mathbb{R}\}$ |

### Limits

- **Definition of the Limit**: $\lim_{x \to a} f(x) = L$ if for every number $\epsilon > 0$, there exists a number $\delta > 0$ such that if $0 < |x - a| < \delta$, then $|f(x) - L| < \epsilon$.
	- $\lim_{x \to a} f(x) = L$ is pronounced as "the limit of $f(x)$ as $x$ approaches $a$ is $L$"
- **Definition of the left-limit**: $\lim_{x \to a^-} f(x) = L$ if for every real number $\epsilon > 0$, there exists a number $\delta > 0$ such that if $a - \delta < x < a$, then $|f(x) - L| < \epsilon$. 
	- $\lim_{x \to a^-} f(x) = L$ is pronounced as "the limit of $f(x)$ as $x$ approaches $a$ from below is $L$"
- **Definition of the right-limit**: $\lim_{x \to a^+} f(x) = L$ if for every $\epsilon > 0$, there exists a $\delta > 0$ such that if $a < x < a + \delta$, then $|f(x) - L| < \epsilon$.
	- $\lim_{x \to a^+} f(x) = L$ is pronounced as "the limit of $f(x)$ as $x$ approaches $a$ from above is $L$"
- **Equality of limits**: The standard (two-sided limit) exists and equals $L$ if and only if both one-sided limits exist and are equal to $L$:
	$$
	\lim_{x \to a} f(x) = L \iff \lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L
	$$

### Continuity

- A function $f$ is **continuous at a point** $a$ if three conditions are met: 
	1. $f(a)$ is defined
	2. $\lim_{ x \to a }f(x)$ exists
	3. $\lim_{ x \to a }f(x)=f(a)$
- A function $f$ is **continuous on an open interval** $(a,b)$ if it is continuous at every point in the interval.
- A function $f$ is **continuous on a closed interval** $[a,b]$ if it is continuous on $(a,b)$ and: 
	- $\lim_{x \to a^+} f(x) = f(a)$ (continuous from the right at the lower bound)
	- $\lim_{x \to b^-} f(x) = f(b)$ (continuous from the left at the upper bound)
- **Intermediate Value Theorem** (**IVT**): Suppose $f$ is continuous on the closed interval $[a,b]$ and let $N$ be any number such that $f(a) < N < f(b)$ or $f(b) < N < f(a)$, then there exists at least one number $c$ in the open interval $(a,b)$ such that $f(c) = N$. 

### Asymptotes

- **Limit to infinity**: $\lim_{ x \to \infty }f(x)=L$ if for every $\epsilon >0$, there exists a number $N>0$ such that if $x > N$, then $|f(x)-L|<\epsilon$.
- A line $y = L$ is a **horizontal asymptote** of the graph of a function $f$ if either: $\lim_{x \to \infty} f(x) = L$ or $\lim_{x \to -\infty} f(x) = L$.
- **Limit of function values to infinity**: $\lim_{x \to a} f(x) = \infty$ if for every number $M > 0$, there exists a $\delta > 0$ such that if $0 < |x - a| < \delta$, then $f(x) > M$.
- A line $x = a$ is a **vertical asymptote** of the graph of a function $f$ if at least one of the following is true: 
	- $\lim_{x \to a^+} f(x) = \infty$
	- $\lim_{x \to a^+} f(x) = -\infty$
	- $\lim_{x \to a^-} f(x) = \infty$
	- $\lim_{x \to a^-} f(x) = -\infty$
- We say that $f(x)$ **approaches** $g(x)$ **as** $x \to \infty$ if the limit of their difference is zero: $\lim_{x \to \infty} [f(x) - g(x)] = 0$.
- A line $y = mx + b$ (where $m \neq 0$) is an **oblique asymptote** if the function $f(x)$ approaches the linear function $g(x) = mx + b$ as $x$ goes to infinity.
- Note: The definitions for $x \to -\infty$ or limits where $f(x) \to -\infty$ are analogous to the versions above, substituting $x < -N$ or $f(x) < -M$ respectively. Similarly, infinite limits can be restricted to one-sided approaches ($x \to a^+$ or $x \to a^-$) by applying the corresponding interval constraints for $\delta$.

### Properties of Limits

- **Calculation rules for limits**: Suppose $\lim_{x \to a} f(x) = L$ and $\lim_{x \to a} g(x) = M$, and $c \in \mathbb{R}$ is a constant. Then:
	- $\lim_{x \to a} [c \cdot f(x)] = c \cdot L$
	- $\lim_{x \to a} [f(x) + g(x)] = L + M$
	- $\lim_{x \to a} [f(x) \cdot g(x)] = L \cdot M$
	- $\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{L}{M}$, provided $M \neq 0$
	- $\lim_{x \to a} [f(x)]^n = L^n$ (where $n$ is a positive integer)
	- If a function $h$ is continuous at $L$, then $\lim_{x \to a} h(f(x)) = h(\lim_{x \to a} f(x)) = h(L)$.
- **Squeeze theorem:** For any three functions $f$, $g$, and $h$: if $f(x) \le g(x) \le h(x)$ for all $x$ in an open interval containing $a$ (except possibly at $a$), and $\lim_{x \to a} f(x) = \lim_{x \to a} h(x) = L$, then $\lim_{x \to a} g(x) = L$.

### Derivative

- The **derivative of a function** $f$ is a new function, denoted by $f'$, defined by:
	$$
	f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}= \lim_{x \to a} \frac{f(x) - f(a)}{x - a}
	$$
	- The domain of $f'$ is the set of all values $a$ for which this limit exists.
- A function $f$ is **differentiable at** $a$ if the derivative $f'(a)$ exists. 
- A function $f$ is **differentiable on an open interval** $(a, b)$ if it is differentiable at every single point in the interval.
- Note: If $f$ is differentiable at $a$, then it is continuous at $a$. The converse is not necessarily true. A function can be continuous but not differentiable at a point (e.g. $f(x)=|x|$ at $x=0$). 

### Properties of Derivatives

| Rule | $h(x)$ | $h'(x)$ |
| :--- | :--- | :--- |
| **Sum Rule** | $f(x) + g(x)$ | $f'(x) + g'(x)$ |
| **Product Rule** | $f(x)g(x)$ | $f'(x)g(x) + f(x)g'(x)$ |
| **Quotient Rule** | $\frac{f(x)}{g(x)}$ | $\frac{f'(x)g(x) - f(x)g'(x)}{(g(x))^2}$ |
| **Chain Rule** | $f(g(x))$ | $f'(g(x))g'(x)$ |

- **Mean value theorem**: If $f$ is continuous on the interval $[a, b]$ and differentiable on the interval $(a, b)$, then there is a number $c$ in $(a, b)$ such that $f'(c) = \frac{f(b) - f(a)}{b - a}$.
- **Implicit Differentiation**: A technique for finding the derivative of a relation that is not explicitly defined in the form $y = f(x)$. It involves differentiating both sides of the equation with respect to $x$ (applying the chain rule where appropriate for $y$) and solving for $y'$.

### Indeterminate forms

**Indeterminate forms**: Expressions where the limits cannot be determined solely from the individual limits of their components. These forms include $\frac{0}{0}$, $\frac{\infty}{\infty}$, $0 \cdot \infty$, $\infty - \infty$, $0^0$, $1^\infty$, and $\infty^0$. 

The main process of resolving indeterminate forms consists of two steps:
1. Rewrite: use conjugates, factoring or logarithms to force the expression into a ratio.
2. Compare speeds: use a comparison in growth rates, or L'Hopital's Rule to see which part of the ratio is changing faster. If the numerator grows faster, the limit goes to $\infty$, if the denominator grows faster, the limit goes to $0$. 

- **Growth rates**: $1 \ll \ln(x) \ll x^n \ll e^x \ll x! \ll x^x$ (more detail: [[Asymptotic Bounds]])
- **L'Hospital's rule**: Suppose $f$ and $g$ are differentiable and $g'(x) \neq 0$ on an open interval containing $a$ (except possibly at $a$). If $\lim_{x \to a} f(x) = 0 = \lim_{x \to a} g(x)$ or if $\lim_{x \to a} f(x) = \pm\infty$ and $\lim_{x \to a} g(x) = \pm\infty$ , then $\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$, provided this latter limit exists. 
	- The rule also extends to one-sided limits and limits as $x$ approaches infinity.

### Extreme values

- Let $c$ be a number in the domain $D$ of a function $f$. Then $f(c)$ is the **absolute maximum** value of $f$ on $D$ if $f(c) \geq f(x)$ for all $x$ in $D$.
- Let $c$ be a number in the domain $D$ of a function $f$. Then $f(c)$ is the **absolute minimum** value of $f$ on $D$ if $f(c) \leq f(x)$ for all $x$ in $D$.
- The number $f(c)$ is a **local maximum** value of $f$ if $f(c) \geq f(x)$ when $x$ is near $c$.
- The number $f(c)$ is a **local minimum** value of $f$ if $f(c) \leq f(x)$ when $x$ is near $c$.
- **Fermat's Theorem**: If $f$ has a local maximum or minimum at $c$, and if $f'(c)$ exists, then $f'(c) = 0$. 
	- Note: The converse is not true in general.
- A **critical number** of a function $f$ is a number $c$ in the domain of $f$, such that either $f'(c) = 0$ or $f'(c)$ does not exist.
- Example: To find the absolute maximum and minimum values of a continuous function $f$ on a closed interval $[a,b]$:
	- Find the values of $f$ at the critical numbers of $f$ in $(a,b)$.
	- Find the values of $f$ at the endpoints of the interval.
	- The largest of the values from Steps 1 and 2 is the absolute maximum value, the smallest of these values is the absolute minimum value.
- Finding the maximum/minimum of a function, possibly under some constraints, is an entire field in and of itself called **optimization**.
