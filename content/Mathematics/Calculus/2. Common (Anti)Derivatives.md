### Power Rule

- $f(x) = x^n$
- $f'(x) = nx^{n-1}$
- $F(x) = \frac{x^{n+1}}{n+1} + C$ if $n \neq -1$, and $\ln(|x|)+C$ otherwise.

### Exponentials

|**$F(x)−C$ (Antiderivative)**|**$f(x)$ (Function)**|**$f'(x)$ (Derivative)**|
|---|---|---|
|$e^x$|$e^x$|$e^x$|
|$\frac{a^x}{\ln(a)}$|$a^x$|$a^x \ln(a)$|
|$x\ln(x) - x$|$\ln(x)$|$\frac{1}{x}$|
|$\frac{1}{\ln(a)}(x\ln(x)-x)$|$\log_a(x)$|$\frac{1}{x \ln(a)}$|

### Trigonometrics

|**$F(x)−C$ (Antiderivative)**|**$f(x)$ (Function)**|**$f'(x)$ (Derivative)**|
|---|---|---|
|$-\cos(x)$|$\sin(x)$|$\cos(x)$|
|$\sin(x)$|$\cos(x)$|$-\sin(x)$|
|$\ln(\mid \sec(x) \mid)$|$\tan(x)$|$\sec^2(x)$|
|$-\ln(\mid \csc(x) + \cot(x) \mid)$|$\csc(x)$|$-\csc(x)\cot(x)$|
|$\ln(\mid \sec(x) + \tan(x) \mid)$|$\sec(x)$|$\sec(x)\tan(x)$|
|$\ln(\mid \sin(x) \mid)$|$\cot(x)$|$-\csc^2(x)$|

### Inverse Trigonometrics

|**$F(x)−C$ (Antiderivative)**|**$f(x)$ (Function)**|**$f'(x)$ (Derivative)**|
|---|---|---|
|$x\arcsin(x) + \sqrt{1-x^2}$|$\arcsin(x)$|$\frac{1}{\sqrt{1-x^2}}$|
|$x\arccos(x) - \sqrt{1-x^2}$|$\arccos(x)$|$-\frac{1}{\sqrt{1-x^2}}$|
|$x\arctan(x) - \frac{1}{2}\ln(1+x^2)$|$\arctan(x)$|$\frac{1}{1+x^2}$|

### Linear Substitution

- If $G$ is an antiderivative of $g$ (that is, $G' = g$), then $\int g(ax+b)\,dx = \frac{1}{a}\,G(ax+b) + C$.
